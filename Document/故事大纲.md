# 《沪上无此人》故事与玩法大纲

版本：0.4｜2026-10-19｜讨论稿，除“已确认”外均可调整。

## 1. 已确认与本稿提案

已确认：2D ARG 类游戏；上海都市传说题材；先确定剧情和核心玩法，再实现程序；确有超自然现象，但部分怪谈是误传；字体资产已有两份，暂不扩充字形；调查过程中并行接触多个都市传说，线索交织推进，不按单个怪谈独立分章；以网站搜索、查找 ID／密码和登录检索为主要玩法，现场以朋友的仿微信消息及照片呈现，通信中断表现遇险，首版不制作可探索场景；主要角色采用女性设定，保留现有姓名。

本稿提案：原创失踪者贯穿多个怪谈；以游戏内网站和仿微信聊天承载调查与叙事；完整单人离线可玩。标题、角色、异常规则、调查阶段和结局都尚待讨论。暂不把本稿当作程序需求冻结。

## 2. 一句话故事

你受邀修复一个即将关闭的上海怪谈论坛，却在旧帖里发现了一位所有人都不记得的高中同学。你每恢复一份关于她的证据，身边就有一份关于你自己的记录开始消失。

首段采用朋友协助迁移旧论坛的普通工作入口，具体内容见[第一段调查内容稿](第一段调查内容稿.md)。先完成搜索、登录与纸档核对，再从朋友最后发来的照片引出失踪同学。`“如果你还记得我，先别在帖子里写出我的名字。”` 留作后续可用台词，不在开场预告全部异常。

情绪核心：从“我记得这个人”走向“我能否让别人也记得她”；从猎奇、辨伪走向失落、牵挂与承担。恐怖主要来自熟悉记录悄悄变化、熟人否认共同经历，以及玩家逐渐失去被他人认识的资格。

## 3. ARG 体验约定

玩家面对的是可以操作的媒介：旧论坛、邮件、聊天记录、照片、音频、地图和备份。线索要跨媒介验证；输入帖子地址、搜索词、档案编号、回复内容等行为，会引发人物回应或材料变化。

主角通过搜索、阅读与登录查资料；一位有自身调查动机的朋友通过仿微信聊天提供现场文字及照片。玩家可通过有限回复请求确认细节，现场与网页信息互相解释。首版不做可走动场景、角色动画、设备操作、调查板与证据卡。通信中断表现朋友遇险，留下可继续搜索的线索，不要求玩家空等。

第一版将 ARG 的调查方法收进游戏内：所有必需网站、账号和通信均为虚构系统，不依赖真实搜索引擎、现实账号、线下到访或开发者实时扮演。可以设计可导出的额外谜面，但主线不能要求玩家打开文件管理器或安装其他软件。

“像真实经历”靠材料之间的连续性实现。开场菜单说明虚构性质；剧情内部不反复打断。NPC 不要求玩家联系真实学校、医院、地铁员工，也不要求前往地下设施。

## 4. 世界真相与规则（作者视角，玩家逐步发现）

上海存在一种暂称“失载”的异常：它会让少数人的身份与经历从可查记录、他人的记忆中脱落。人并不立即死亡，而是逐渐无法被世界准确指认。异常起因暂不解释到底，避免第一部过早讲完全部宇宙观。

失踪者曾与一群民间怪谈整理者合作，发现一些流传多年的故事中夹着真正的求救。她们尝试把失载者的经历藏进会被反复转述的怪谈里，让故事替真人保存痕迹。后来大量搬运与添油加醋，把原始证词变成了互相矛盾的恐怖段子。

这些人并未创造所有上海怪谈，也没有操控现实机构。各个传说是她们收集、误读和利用过的材料节点；不设定现实地下存在连接所有地点的秘密工程。

规则：

1. **身份依赖多份独立见证。** 一张照片或一条自述只能留下残响；来自不同来源、相互支持的证据才能稳定一个人。同一原帖的一百次转载仍只算一个来源。
2. **异常可以改写联网记录和非稳定记忆，不能任意抹除一切。** 旧纸张、离线录音和已封存的备份会保留碎片；关键旧记录和聊天图片始终可回查，保证谜题有据可查。
3. **传播能保存痕迹，也能用误传覆盖真人。** 被广泛记住的“地下鬼影”可能长存，鬼影对应的具体人却仍在消失。转发量不是救人的进度条。
4. **失载会影响地点与记录之间的对应关系。** 玩家通过网站记录指导朋友确认现场细节，朋友的照片又为后续检索提供入口；首版不把进入异常空间做成玩家直接操作的关卡。账号密码只取得相应系统的访问权限。
5. **为失载者作证会暴露见证者。** 恢复关键证据后，主角身份开始出现缺口；升级按关键调查事件触发，不设置挂机惩罚或不可见的实时倒计时。
6. **并非每个鬼故事都有异常。** 真正异常要有跨来源的不可能矛盾支撑。单纯冷风、声控灯、扶梯异响不构成证据。

核心反转：寻找“恐怖故事共同的地下通道”是错误方向；这些故事真正连接的是被遗漏的人和被篡改的见证。

## 6. 连续调查结构：多条线索交织，同一条主线升级

### 结构原则（用户已确认）

调查过程中可以同时了解多个都市传说，不采用“一章一个怪谈”的结构。开端、发展、高潮与收束服务于整场调查；每个怪谈只贡献部分材料，不各自完成一轮独立故事。以下阶段供作者控制节奏，默认不在游戏里弹出章节结算或切断当前调查。

玩家当前关心的问题持续存在：最初是“这个人是谁”，随后是“她为什么出现在这些材料里”，再变成“为什么我也在其中”，最后是“怎样才能把她带回来”。一个问题得到回答时，下一个问题已由先前的证据自然产生。

所有异常、私人档案、内部空间、人物经历均为原创。真实地名仅作为都市文化坐标，不代表当代现场布局。

### 阶段一：同行者

主角在家协助朋友周祁迁移旧论坛。周祁在获准进入的虚构旧站资料室整理纸档，发来只读索引地址和搬迁阅览口令。玩家搜索旧整理者“回声17”，从论坛帖子进入一篇虚构小报报道，在配图的资料员卡上找到用户 ID，登录资料目录。

商场采访与漕宝路录音同时出现，二者都指向纸档箱 B-06。周祁发来的照片也拍到这个编号，旁边的来访登记表只填了她自己的名字。玩家按箱号查到一份历史说明：当年一名整理者独自来访，登记表的同行者栏却多了一个名字。

玩家提醒周祁离开或请她查看登记表。她听见手机里有人叫自己的名字，而主角没有发过语音。最后一张照片里，原本空白的同行者栏出现“沈叙”。周祁发来“我没填这个”后不再回复。

玩家可以沿历史说明留下的 Q-17 签收单与“第二个人”录音继续搜索，调查由普通归档变为“周祁身边是谁，沈叙为什么出现在那里”。主角与沈叙的旧同学关系在此逐渐引出，不把潘博文原作的天津经历搬到上海。

具体页面正文、输入和消息顺序以[第一段调查内容稿](第一段调查内容稿.md)为准，仍是待讨论的制作提案。

### 阶段二：她不该同时出现在这里

围绕同一个失踪者，玩家在两三个问题间往返：商场录音到底录于何处；站台照片究竟拍于哪一年；不同怪谈帖里的上传者是否认识彼此。

商场广播单只能解释一部分音频。漕宝路材料中的报站顺序帮助玩家确认：音频是有人按顺序拼接的调查记录，其中的停顿不能直接当作闹鬼证据。与此同时，龙柱旧帖里的原图署名，使玩家找到了录音上传者更早的账号；该账号收藏的旧校园借阅记录又给照片定下了日期。

这里需要保留各怪谈自身的质感：循环歌声与闭店广播、末班车和站台远端、桥下车流与旧照片、校园走廊和纸质借阅卡，分别提供不同的信息与恐怖体验。它们无需都出现同一个密码或同一种鬼影。

玩家通过跨来源材料辨认出沈叙。她曾沿着这组线索调查，而且在一段早期录音中，有人与主角使用相同的说话方式。这个声音暂时无法确认，留下持续悬念。

阶段转折：当玩家首次拼出沈叙的一段完整行程，相关旧帖发生联动变化；朋友此前发来的旧截图仍可在聊天中查看。主角的旧同学却不再记得某次与主角共同参加的活动。调查对象与调查者的处境开始重叠。

### 阶段三：我们以前来过

玩家已有足够的地点、日期与账号线索，可以尝试解释它们的共同关系。此时“龙柱地下入口连通各处”“地铁通往天佑楼地下三层”等说法看起来很有诱惑力；匿名协助者也相信其中部分说法。

这些假说必须可验证、可推翻。玩家将两组帖子的引用时间、原图和账号关系放在一起，发现多条所谓独立见证实际出自同一次转载。具体物理通道的说法被推翻，但同一组整理者曾经收集这些材料的事实得到加强。相同账号本身只证明收集关系，真正的超自然联系仍需要独立原始记录。

关键证据分散在先前接触过的材料里：商场员工记录保留一名受访者的声音，旧校园借阅卡保留其姓名，站台影像保留其与沈叙见面的过程。这些组合起来，才显露沈叙试图为一个被怪谈匿名化的人恢复身份的目的。此时仍有材料缺口，不能直接给出全貌。

许澄因玩家找到自己的旧账号而主动介入。玩家可以拿已掌握的具体矛盾询问她，她的回答改变旧材料的读法。通过与另一段独立录音比对，主角终于确认：自己当年也在场，并曾同意许澄删去一部分原始证言。

阶段转折是一次信任与自我认识的破裂：委托不再只是修复别人的旧站，主角必须面对自己参与过的决定。前面留下的“为什么找上我”和“那是谁的声音”在同一处得到回答，随后自然转向“我们当年到底做错了什么”。

### 阶段四：记录开始认不出你

身份缺口加剧，玩家需要回访已经熟悉的网页、联系人和朋友发来的现场图片。世界变化要有连续因果：某份证言得到恢复后，一位联系人开始无法准确叫出主角名字；某段档案被重新解释后，过去无法进入的失载空间有了锚点。

朋友根据玩家查出的旧记录前往确认，陆续发回站台、门牌与楼梯照片。玩家从照片中的编号搜索新记录，再把重要发现通过有限回复告知朋友。站台与楼梯只通过消息、关键图片和少量声音呈现，不制作探索关卡；消息在一次关键信息矛盾后中断，玩家仍可沿已收到的照片继续调查。朋友身份与既有角色的关系待定。

玩家发现沈叙的失败原因：她保存了故事，却没有保住足够独立、具体的人际见证，最后又把压力集中到自己身上。许澄的保护动机、删帖后果与主角当年的约定在此补齐。

所谓“地下三层”只能作为尚待讨论的原创失载空间表现，不是现实建筑层，也不是全地图的物理中心。它的进入条件来自证据的完整性，不以走完所有怪谈地点作为钥匙。

此阶段的目标始终明确：取得足以让具体的人认出沈叙的见证，并保住还能回应主角的联系人。玩家可选择先补哪份证言，但剧情高潮由关键事实与人物回应共同触发，不要求清空所有支线。

### 收束：请确认此人存在

最终操作发生在玩家一路使用的档案和通信环境里。玩家用已出现的事实恢复沈叙的姓名、经历、关系与关键行动，决定保留什么、向谁提供，以及如何取得独立见证。不临时引入新密码规则，也不靠额外旁白一次解释全部真相。

同一份档案会同时引用几处传闻里的原始材料；此前每次调查都参与最后的判断。结局由具体证据关系和见证者选择触发，界面不给抽象的善恶分数。

| 结局方向 | 触发逻辑 | 后果与情绪 |
| --- | --- | --- |
| 留名（主结局） | 恢复关键独立证言，取得具体见证者的确认，保留原始档案及上下文 | 沈叙重新能被有限的人认识；异常未彻底消失，但主角不再独自承担。最后一张合照中的位置被一个真实的人坐满 |
| 流传 | 在证据未核实或关系未复原时，把碎片拼成最易传播的怪谈公开 | 帖子爆红，“失踪同学”被所有人听说；沈叙仍无人真正认识，甚至开始照着故事中的形象出现 |
| 封存 | 完成调查但拒绝继续提供见证，主动隔离材料 | 主角保住较完整的生活记录；沈叙只能留在离线档案中。保留重开调查的余地，不以羞辱玩家作为结尾 |

结局分支只是方向，暂不确定数量；不能要求收集所有彩蛋才能达成主结局。

### 线索交织与调查自由度

以下是待细化的依赖示例。每个结论都需要跨来源推理；“材料中出现了某个地名”不足以建立因果关系。

| 当前悬念 | 已有材料 | 从另一线获得什么 | 回看后推进什么 |
| --- | --- | --- | --- |
| 商场录音为何出现不合场景的间隔 | 闭店广播、录音片段 | 站台记录中的广播顺序 | 确认音频拼接顺序，恢复一次调查的经过 |
| 站台照片是哪一年的 | 上传日期、旧图 | 校园材料中的同一张未裁剪照片及借阅日期 | 排除错置年份，确认照片人物关系 |
| 多个地点为什么都有同一种通道说法 | 龙柱帖、李子园帖 | 旧论坛备份中的引用链 | 识破同源转载，追到整理者与删帖经过 |
| 主角是否真的参与过 | 地铁材料里熟悉的声音 | 商场采访原件、许澄持有的独立记录 | 确认主角过去的行动，重新解释委托 |
| 如何让沈叙被认出 | 各处遗留的身份碎片 | 独立见证者对具体经历的确认 | 汇成可验证的个人档案，进入最终抉择 |

前期允许两条主要调查方向，熟悉操作后可同时保留两到三个明确悬念。地点资料可以早见，访问深度随证据增加；不同时倾倒所有帖子与术语。关键转折依赖事实成立与人物回应，同一阶段内的取证顺序可变，后期逐步汇合。

已看过的材料应在获得新证据后产生可理解的新用途。通过浏览历史、旧聊天和可放大图片支持便捷回访，减少重复翻找；不设置调查板或按怪谈显示完成百分比。允许局部验证成功的满足感，主要悬念与人物关系继续推进。

## 7. 核心玩法循环（按用户反馈简化）

**搜索关键词 → 阅读帖子／报道／图片 → 找到 ID、密码或编号 → 登录与检索 → 发现新记录 → 与朋友通信 → 用新线索继续搜索。**

玩家自己在脑中连接信息，程序校验明确的账号、密码、编号和回复，不要求收集证据卡、连线或提交抽象结论。查找账号和密码可以并行；同一网站中的材料关联多个传说，继续维持连续调查。

例：朋友提供旧系统的共用阅览口令，玩家从帖子里的旧截图找到当事人的用户 ID，登录后取得一组商场与地铁调查记录。朋友发来的现场照片里又有档案编号；玩家查到记录与现场消息矛盾，准备提醒时，朋友的消息突然停止。最后一张图片还留有可调查的线索。

谜题变化来自材料出处与用途：昵称对应登录 ID、新闻附图中的编号、照片里的旧门牌、私人记录中的检索词。保留来源追查与误传辨别，但不为其开发专门判定界面。密码需要合理来由，避免所有谜题都变成猜生日或无提示穷举。

搜索支持常见简称与关键词组合，图片可放大，关键字符可辨认。正确凭据可以提前使用，不强制先读指定页面；错误输入可重试。现场风险由剧情事件推进，不以真实等待时间惩罚读得慢的玩家。

## 8. 首段可玩调查（讨论通过后再实现）

只做一个搜索入口、论坛与报道页面、一个登录检索系统、一个联系人及少量关键图片。界面以少数模板复用，不实现完整操作系统、真实联网网站或微信接入。

做通：朋友给密码 → 玩家搜索找到 ID → 登录后取得跨传说记录 → 朋友传现场照片 → 根据图片编号检索出矛盾 → 通信中断，留下下一步搜索方向。

样段重点验证搜索是否自然、信息是否可读、账号密码来由是否可信、聊天是否让玩家关心现场朋友，以及失联后是否仍知道能查什么。美术优先服务含线索的关键照片，现场不制作可探索地图与角色动画。
