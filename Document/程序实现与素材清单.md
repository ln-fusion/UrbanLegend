# 原型编辑与素材清单

2026-10-19。已从运行时生成布局改为编辑器内保存的场景与 Prefab。运行时只绑定交互、显示页面、填充动态列表及存读档。本文为当前编辑方式的准则，替代旧的运行时生成方案。

## 在哪里改

打开 `Assets/Scenes/ArgPrototype.unity`，无需 Play 就能看到主界面和初始聊天示例。场景内的 `ArgPrototype` 组件已绑定实际 UI 对象和样式 Prefab。

| 要调整什么 | 编辑位置 |
| --- | --- |
| 网页／聊天宽度、工具栏位置、整体背景、顶部标题 | 场景 `ArgPrototype / ARG Desktop` 下的 Browser、Chat、Toolbar 等对象 |
| 某篇网页的正文、标题、独立布局 | `Assets/Prefabs/Arg/Pages/Page_*.prefab`，或场景对应实例；Title／Body 为正常 TMP 组件 |
| 页面地址、来源、搜索别名、权限、链接目标 | 页面上的 `ArgPageView` 组件；搜索索引启动时从这些场景组件读取，不另读 JSON 覆盖文字 |
| 所有正文默认字号、颜色 | `Assets/Prefabs/Arg/Styles/Body.prefab`；页面继承它，可做单页 override |
| 聊天字体／回复按钮 | Styles 下的 ChatName、ChatBody、ReplyButton、PhotoButton 等 Prefab |
| 输入框字体、边框、底色 | Styles/Input.prefab；已在地址、登录和检索表单中实例化 |
| 文章留白与行距 | Pages/PageLayout.prefab 的 VerticalLayoutGroup；文字行距在 TMP 上改 |
| 聊天列表与回复区间距 | 场景 Chat/Messages/Viewport/MessageList、Chat/Replies 的 LayoutGroup |
| 图片、线索文字及位置 | `Assets/Prefabs/Arg/Photos/Photo_IMG*.prefab` 的 RawImage、ClueOverlay、ClueText |
| 图片弹窗、缩放按钮、重新开始确认框 | 场景 ARG Desktop/Modal 下的 PhotoViewer、RestartConfirmation |

不需要的叠字可直接禁用 ClueOverlay，不会在 Play 时被程序重新打开。主界面锚点、字号、颜色、边距在 Play 时不再由代码重设。图片缩放只在用户查看和点击缩放时改变，不重建查看器。

正文用 LayoutGroup 自动排版；想改高度看 LayoutElement，想改留白看 LayoutGroup，直接拖被布局控制的子对象会被 Unity 布局恢复。单篇图文若需要特殊布局，可在其 Prefab 中调整／移除对应布局组件。

## 页面与 Prefab 的关系

每篇页面是独立的 Prefab Variant，继承 PageLayout。场景引用这些页面实例，运行时仅切换显隐，不销毁或重做文章、登录框和检索框。

常用页面：Page_thread（旧帖）、Page_report（报道）、Page_login（登录）、Page_directory（检索目录）、Page_record（R-02）、Page_continuation（后续求档帖）。

场景中的 Pages/Viewport 下同时保留 Home、SearchResults、HistoryResults 及全部文章页。默认只显示 Home；想预览某篇，可先关 Home，再启用对应页面。运行时按存档选择页面。

Modal 默认关闭，展开并临时启用可编辑查看器和确认框；预览图片时启用其中一个 Photo_IMG* 实例即可。避免同时启用多张图片。

Home 和固定按钮直接在场景改，记得保存场景。页面／图片／样式推荐打开 Prefab Mode 改源文件；若在场景里改实例，保存场景即可生效，Apply 可同步回 Prefab。

搜索结果、浏览历史、聊天消息及回复仍然是动态数量的列表，运行时从 Styles Prefab 实例化，只填文字、绑定点击，不覆盖样式。编辑器中的 Preview_* 是初始聊天示例，文字与对象会在运行时替换；应改样式 Prefab 来统一调整，聊天实际台词在 ArgSession.cs 中维护。

FirstInvestigation.json 只保留首次迁移数据，已不作为运行时页面或图片来源。日常改稿直接改页面 TMP、ArgPageView 和图片 Prefab，不必再同步 JSON。

## 文件职责

- ArgDesktop.cs：绑定已有场景组件、路由页面、实例化动态列表、图片缩放、存档；无运行时 AddComponent／new GameObject 生成 UI。
- ArgPageView.cs：每篇实际网页的组件引用、地址、来源、别名、权限和链接。
- ArgPhotoView.cs：图片 ID、标题、说明、RawImage、可选叠字层。
- ArgSession.cs：账号密码判定、剧情节点和聊天内容。
- ArgContent.cs：搜索数据结构与匹配。
- ArgUiAuthoring.cs：一次性迁移工具，仅在 Editor 内执行；已有 Prefab 时拒绝重建，避免覆盖手工微调。日常无需使用。
- ArgPrototypeChecks.cs／ArgVisualChecks.cs：逻辑与比例回归检查。
